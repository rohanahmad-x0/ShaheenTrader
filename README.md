# Shaheen Nut Bolt Traders website source

Self-contained static website source, including the supplied eagle logo and bundled fastener hero image.

## Run locally

With Python 3 installed, open a terminal in this folder and run:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000. Google Fonts are loaded from Google when available, with system fallbacks.

`app.config.ts` contains Manus project branding metadata and is not required for a local preview. Product categories are inquiry prompts; confirm exact products, sizes and availability with the business.
